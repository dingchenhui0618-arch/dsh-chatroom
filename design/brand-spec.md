# 品牌资产：DSH 鲸

## 来源

宿主桌面端的应用图标：`D:\.deepseek\resources\icon.png`（1024×1024，黑鲸在白色圆角方上）。
把它按「深色像素 + alpha 掩膜」抠出来，去掉白色底与投影，得到只有鲸形的透明 PNG：

- `design/assets/whale-black.png`　752×554，黑色鲸形（白底/浅色底用）
- `design/assets/whale-white.png`　同样尺寸，白色鲸形（深色底用）
- `design/assets/whale-black-half.png`　半尺寸，给小尺寸做锐利降采样

抠图脚本：`design/tools/extract-whale.py`（Pillow，阈值 lum < 130，保留眼与腹部的负形）。

## 用在哪

| 位置 | 尺寸 | 形态 |
| --- | --- | --- |
| 侧栏入口（宿主图标栏） | 32×32 圆角 3–10px | 浅色底 + 黑鲸，和 DSH 自己的应用图标同一套语言 |
| 浮窗标题栏 | 26–28px | 同上 |
| 托盘（胶囊/票签/载波胶囊） | 24–34px | 深色底用白鲸；浅色底用黑鲸 |
| 收起后的圆标 | 48px | 浅色底黑鲸 + 一圈声呐环 |
| 空状态/水印（未用） | ≥96px | 白色 6–8% 透明度，只做背景 |

## 规矩

- **最小 16px**：再小鲸的尾鳍会糊；16px 以下改用「鲸 + 冒泡」的简化符号。
- **不拉伸**：等比缩放，比例固定 752:554。
- **不上色**：鲸只有黑与白两种状态，彩色留给状态色（LAN / 授权 / 未读），不要给鲸加渐变或彩色发光。
- **描边不叠**：鲸是实心剪影，外面最多一圈 1px、8–18% 透明度的环，别做多层描边。
