# 三个方向：先把「骨架」换成有主见的一间屋子

同一份真实内容、同一块 1440×900 画布、同一套宿主 token（`#151517` 底 / `#f9fafb` 文字 / 发丝线），
三套不同的设计逻辑。每版都给了：面板（1440×900）+ 组件板（托盘三态 / 浮窗 / 动效）

## 六个候选，三个做成完整版

| # | 方向 | 一句话 | 状态 |
| --- | --- | --- | --- |
| 1 | **深渊回声** | 屋子在深水里，光从上面来，鲸是屋主 | ✅ 完整版 `demos/A-abyss.html` |
| 2 | **墨鲸手记** | 一间屋子像一本手记：落笔、划线、盖章 | ✅ 完整版 `demos/B-ink.html` |
| 3 | **信号舱** | 每个成员是一个频道，消息带序号，托盘是载波 | ✅ 完整版 `demos/C-signal.html` |
| 4 | 深海玻璃 | 磨砂玻璃面板 + 背景模糊 + 光斑折射 | 备选：糊在 DSH 的纯色底上没东西可透，性能也贵 |
| 5 | 航海图 | 房间是一张海图，成员是航标，频道是航线 | 备选：地图隐喻压过内容，读消息要先读图 |
| 6 | 纸带电报 | 消息像电报纸带从机器里吐出来，等宽字 + 打孔 | 备选：和 3 太近，且长消息会变成一条窄纸带 |

三个完整版分别对应三种「离宿主多远」：A 最近（宿主自己的语言，只加一层水光），
B 最远（衬线 + 印章 + 票签，像一件东西），C 在中间（仪表面板，数据密度最高）。

## A · 深渊回声

**设计逻辑**：聊天室是一间在深水里的房间。光只从上面来（顶部一层 1200×320 的冷光，不是整屏渐变），
鲸是屋主 —— 侧栏、浮窗头、托盘、圆标都是它，正在发言时它冒泡。颜色只多一个：生物光的青色
（`#7fe0cf`），只出现在「有人在说话 / 这条消息刚到 / LAN 在线」这三件事上。

**结构**：三列骨架不动（这是 DSH 的），但把「谁在说话」变成了现场：消息逐条落水、发言中的 agent 头像是活的、
房间头一条 1px 冷光每隔 9 秒横穿。

**托盘**：声呐胶囊。左边鲸在一个浅色圆里，外圈一圈声呐环，新消息到达时只打一环；未读用数字徽标 +
`Counter` 式的数字翻牌；拖到角落会缩成一枚 48px 圆标（鲸 + 未读 2），点开还是同一间屋。

**动效清单**
- 鲸呼吸：6s，圈透明度 .55 → .15（只在标记外一圈，不是整块发光）
- 声呐：新消息 2.4s 扩散一次，只打一环
- 落水：新消息 8px 上浮 + 2px 模糊，260ms 收住
- 冒泡：正在发言的三颗气泡 4px 上浮，错 0.18s（`Voice Pill` 的节奏）
- 格阵：发言等待从三点改成 8×2 的格子波 + 计时（`Lattice Loader`），比「…」多一个「在算多久」
- 涟漪：发送按钮中心一点扩散，只在真发出去时
- 光扫：房间头 1px 冷光每 9s 横穿一次

**ReactBits 参照**：`Voice Pill`（说话时胶囊变成均衡器 + 计时）、`Lattice Loader`（格阵 + 秒表）、
`Counter`（未读数翻牌）、`Spotlight Card`（托盘 hover 时边缘一圈灯跟着指针）、`Animated List`（消息入场的错峰）。

**代价**：最克制，但和现在最像。真正拉开差距的是托盘、鲸和格阵三处。
**风险**：青色如果调亮一点就会变成「AI 味霓虹」，所以固定在 40% 饱和度、只做 1px 线和 8–14% 填充。

## B · 墨鲸手记

**设计逻辑**：一册线装手记。鲸是扉页上的墨痕；人说话是落笔，agent 说话是另一种笔迹，发送是盖章。
底色压到暖炭 `#131211`，正文用暖白 `#f1ece1`，衬线只给标题、名字和数字 —— 正文仍是黑体（中文长文衬线会累）。
唯一的彩色是印章红 `#c65a3f`，只给三件事：远程/LAN、正在写、拒绝。

**结构**：房间列表变成「目录」（发丝线分隔、选中的那间是一个实心小方块，不是圆点）；
消息徽记从圆头像改成**方形印章**（人=实心、agent=空心、远程=虚线）；远程消息左侧一条虚线轨，
一眼分得出是从哪台机器来的；输入器没有边框，只有一条底线，下面写「以 林岸 的身份落笔」。

**托盘**：票签。左边一个打孔缺口，左边沿一道红脊，中间房间名 + 最后一句，右边虚线撕口隔出票根，
票根上盖着未读数（`02`）和 `NEW`。新消息时缺口处一圈红环脉冲一次；这张票签可以被「撕下来」收起（`Tear Ticket`）。

**动效清单**
- 落墨：新消息从 3px 模糊里显影，600ms（不是一个一个滑进来）
- 盖章：发送后一枚 78px 的鲸印从 1.7 倍按下、带一圈压痕扩散；按住不放可以撤回
- 划线：正在发言的名字下面一条红线来回生长
- 翻页：切房间时一条 1px 竖线从左到右扫过
- 缺口铃：票签缺口一圈红环，2.2s 一次，只在有新话时
- 显影：连续同一人发言时，印章不出第二遍
- 授权：**按住 600ms 才批**（`Hold Button` 的液体填充），比点一下更难误触 —— 这是「别的机器要在这台机器上跑东西」唯一的确认

**ReactBits 参照**：`Tear Ticket`（票根撕口）、`Hold Button`（按住授权）、`Thought Line`（"正在写…"折成一行带时钟）、
`Status Mark`（agent 状态环 → 弧 → 勾）、`Swipe Toast`（提醒带一根燃尽的时间条）。

**代价**：气质最像「有人设计过」，但离 DSH 自己的界面最远（衬线 + 红印不是宿主的语言）。
**风险**：中文衬线在 Windows 上落到 SimSun，标题会显得旧；要用「标题用衬线、正文黑体」的分工，别让衬线进正文。

## C · 信号舱

**设计逻辑**：一间调度台。每个成员是一个频道（L1 我、A1 账期、A2 退货、A3 尾货、R1 周荻），
每条消息带序号（#55…#61）；房间头一行遥测（PEERS 5 / LAN 2 / SEQ #62 / ● LIVE）。
颜色是单色的，只留一个信号绿给「在线/正在算/新消息」。

**结构**：变化的不是颜色，是**信息**：消息左侧一列呼号、右侧一列序号，成员列每行带频道与机器，
底部输入器是一条命令行（`>` 提示符 + SEND），而不是一个聊天气泡输入框。房间列表用信号格代替圆点。

**托盘**：载波胶囊。左边一个 30px 的方框里五根柱子实时跳（`Voice Pill`），中间房间名 + 最后一句（逐字打出），
右边票根是 `02 / NEW` 的翻牌读数；新消息时胶囊外圈一圈 conic 光扫过（`Border Glow` 的机制，静态图里在中间帧）。

**动效清单**
- SCAN：新消息到达，房间头一条 2px 亮线扫过一次
- LED：LAN 在线灯 3.2s 呼吸，掉线转灰
- WAVE：正在发言的频道五根柱子错峰起伏；等待时换成格阵 + `00:04`
- COUNT：未读数翻牌，旧数向上滚出
- TICK：新消息左侧 2px 亮条亮 1.6s 后回落到 35%
- TYPE：胶囊里最后一句逐字打出，只在它变化时
- 派发：轮到远程 agent 时出现一枚 `CALL 派发中 00:03` 的计时芯片（`Call Chip`）

**ReactBits 参照**：`Voice Pill`、`Counter`、`Call Chip`、`Lattice Loader`、`Border Glow`、`Prompt Bar`（输入器带 @ 来源与模式位）。

**代价**：动效最多、最「有东西」，但信息密度也最高，第一次进屋的人要先学会读呼号。
**风险**：容易滑向「终端玩具」；控制办法是呼号只在消息和成员列出现，正文永远是人话，不出现代码感。

## 选定之后的实现边界

三版都能落到现有的 `lib/client.js`（纯 CSS + 少量 JS，不加依赖、不用构建）：

- 颜色全部进 `--cr-*`：新增 `--cr-live` / `--cr-seal` / `--cr-on-live` 三个，其余沿用宿主 token；
- 动效只用 `transform` / `opacity` / `filter`，全部包在 `prefers-reduced-motion` 里；
- 托盘与浮窗共用同一套消息行与输入器（这条不能破，否则两条时间线会分叉）；
- 鲸只用一份 PNG（或重绘的 SVG），在 rail / 浮窗头 / 托盘三处复用；
- 截图脚本要新增「托盘三态」与「授权按住」两屏，并且能逐字节复现（动画钉在固定帧）。

成本估计：A ≈ 1 轮（改样式 + 3 处 JS）；B ≈ 1.5 轮（印章/票签/按住授权都是新结构）；C ≈ 1.5 轮（呼号/序号要接到真实数据上）。
